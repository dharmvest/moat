## 第一夜 · 八分之一美元

| | |
|---|---|
| **核心场景** | 一九六四年五月六日。口头承诺 $11.50，信里写着 $11.375 |
| **底层规则** | 情绪是资本配置的敌人；一笔糟糕的买入可以被持有二十年 |
| **反常识** | **微不足道的傲慢，决定了最大的代价。**八分之一美元对两个人都算不了什么，而它让一个人失业、让另一个人丢掉一千亿美元 |
| **心理学原型** | **阴影的诞生**——他后来用最不体面的方式把它写在信里，年年重读 |
| **关键数字** | $11.375 / $11.50 / $100,000,000,000 |
| **呼应** | 他是"追上汽车的狗"；那辆车是第二夜 |

## 第二夜 · 雪茄烟蒂

| | |
|---|---|
| **核心场景** | 一九八六年的拍卖会。$5,000 买的织机，$50 无人要，$26 当废铁卖掉，不够运费 |
| **底层规则** | **时间是优秀生意的朋友，是平庸生意的敌人** |
| **反常识** | **便宜是昂贵的。**资产负债表上的折扣，会被生意本身的低回报吃干净 |
| **反人性** | **"我已经投了这么多。"**——全人类最贵的一句话 |
| **心理学原型** | 沉没成本；"理智应当是心灵的仆人，但不是它的奴隶"（孔德） |
| **关键数字** | 拍卖净收益 **小于零**；两条送报路线的商誉 > 七十五万平方英尺厂房 |
| **人的代价** | 缅因州 1,600 名鞋厂工人；新贝德福德只会说葡萄牙语的老人，"没有 Plan B" |
| **呼应** | "踮脚看游行"——集体理性如何变成集体非理性 |

## 第三夜 · 市场先生

| | |
|---|---|
| **核心场景** | 一九八六年的农场（$28 万，400 英亩，28 年只去看过两次）／一九九三年的纽约大学旁地产（$5 对 $70 的租约，"纽约大学不会搬走"） |
| **底层规则** | 报价是**服务**，不是**指导**。你永远不必接受它 |
| **反常识** | **流动性从无条件的好处，变成了诅咒。**有报价的人比没报价的人更容易变穷 |
| **反人性** | 人在为即将买入的"汉堡包"涨价而欢呼 |
| **心理学原型** | 集体情绪感染；"大多数人宁愿死也不愿思考。很多人确实这么做了"（罗素） |
| **语言病理** | 市场说的不是"价值"，是"价格"。混淆这两者，是一切幻觉的来源 |
| **关键数字** | 华盛顿邮报：一美元的东西卖二十美分（**三重下跌**） |
| **呼应** | 市场先生是他自己请来的 |

## 第四夜 · 卖得便宜，说真话

| | |
|---|---|
| **核心场景** | 一九八三年八月三十日，他的生日。一又四分之一页的收购提案，$5,500 万支票换一句话 |
| **底层规则** | **信任比审计便宜**。护城河最深的一段，是品格 |
| **反常识** | 一个**一天学都没上过**、不会说英语的移民，把一家店做成美国第一 |
| **反人性** | 人对"便宜"的理解停留在价格上；她理解的是成本结构 |
| **心理学原型** | **大母神**。她给的不是低价，是"真话"这个不可能被复制的东西 |
| **关键数字** | $500 → $6,000 万；1946 年净资产 $72,264，手上现金 $50（没有省略任何一个零） |
| **弧线** | 89 岁卖出 → 96 岁辞职出走 → 99 岁主动签竞业协议 → 100 岁把生日派对推迟到商店不营业的晚上 → 103 岁停止工作 → **第二年去世** |
| **呼应** | 阿尔伯克基 263 封信的顾客起义；"我能卖这么便宜，是因为我在给一个对地毯一窍不通的假人打工" |

## 第五夜 · 护城河

| | |
|---|---|
| **核心场景** | 一九五一年一月，一个星期六。大楼关着。一个看门人打开了门。六楼有一个在工作的人，给了他一堂课 |
| **底层规则** | 护城河只有几种：最低成本、品牌、网络。**必须不断重建的护城河，等于没有护城河** |
| **反常识** | **护城河不是墙，是每天挖一铲土。**没有人会为此鼓掌 |
| **反人性** | 人愿意为"看得见的城墙"付钱，不愿意为"看不见的日常"付钱 |
| **心理学原型** | **共时性**——那个看门人。"我欠托尼和戴维一笔巨债，想到这儿，也欠那位看门人一笔" |
| **关键数字** | 成本占保费 23.5%，对手高 15 个百分点；前半股权 $4,700 万，后半 $23 亿（**50 倍**）；市场份额 2.5% → 12% |
| **机制** | 那多出来的一半是公司自己回购出来的——**"而我们没有多花一分钱"** |
| **呼应** | "如果一门生意需要一位超级明星，它本身算不上伟大生意"（梅奥诊所 vs 脑外科医生） |

## 第六夜 · 不属于我们的钱

| | |
|---|---|
| **核心场景** | 一九八六年，巴菲特接下劳合社三百年累积的石棉负债。names 的无限责任："直到最后一颗袖扣" |
| **底层规则** | **先收钱、后付钱**的生意，拿到的是别人的钱，而赚到的全归自己 |
| **反常识** | **负债可以是资产。**"欠一美元而它永远不会离开这栋房子，与欠一美元而它明天就要出门，是两个世界——而会计把两者当作同等的" |
| **反人性** | 人无法为三十年后的账单定价，因此倾向于为它打八折 |
| **心理学原型** | **集体无意识**——劳合社三百年保住了袖扣的记录，然后被一场无限责任击穿；有人破产，**有人自杀** |
| **关键数字** | 浮存金 1970 年 $3,900 万 → 2024 年 **$1,710 亿**（近 5,000 倍）；累计承保利润 $320 亿 |
| **最狠的一句** | "损失并没有'发展'——它们一直都在那里。**发展的是管理层对损失的理解**" |
| **呼应** | "租来的西装"；"世界最好的床垫"；"谁愿意为自己准备死刑执行文件呢？" |

## 第七夜 · 吻过蟾蜍的人

| | |
|---|---|
| **核心场景** | 一九六五年，芒格递来一句话："抛弃你从你的英雄本·格雷厄姆那里学到的一切。那方法管用，但只在小规模时管用" |
| **底层规则** | **好生意 > 好经理。**"当一位以才华著称的管理者，去接手一家以糟糕基本经济特征著称的企业时，最终保持完好的是那家企业的名声" |
| **反常识** | **一家需要极少有形资产的强势特许经营权，是把通胀变成礼物的机器** |
| **反人性** | 公主永远看得见王子。**"我吻了，它们叫了"** |
| **心理学原型** | **个体化**——他花了二十多年，才把老师的东西换成自己的东西 |
| **关键比喻** | 好骑师骑好马；一英尺高的栏架；"我曾是白雪公主，但我随波逐流了"（梅·韦斯特） |
| **最毒的一句** | 芒格："**我们是不是该鼓掌，就因为往我们草坪上拉屎的狗是奇娃娃，而不是圣伯纳？**" |
| **真例外** | GEICO 不是"反转"，是"**一个局部的、可切除的癌**"——需要外科医生，不需要皮格马利翁 |

## 第八夜 · 组织有自己的意志

| | |
|---|---|
| **核心场景** | 一九八九年的**高尔夫记分卡寓言**：先写 140 杆建立"储备"，然后"重组"挥杆，此后只计算好洞 |
| **底层规则** | **制度性强制力**的四条表现：抗拒改变／项目为吸收资金而诞生／下属为上司的欲望提供研究／盲目模仿同行 |
| **反常识** | **不是腐败或愚蠢把企业推上歧路，是制度动力。**每个参与者在自己位置上都是对的 |
| **反人性** | 组织比个人更不理性，因为组织不需要一个人承担后果 |
| **心理学原型** | **集体无意识**（荣格最直接的一次对应） |
| **语言病理** | 这一夜通篇是维特根斯坦式的：**语言的腐败先于数字的腐败** |
| **关键案例** | "损失发展"、"准备金强化"、EBITDA、"二加二等于几？""您心里想的是几？"；参议院 88:9 封杀 FASB；银行家："**我们会做得比那更大——这正是我们做这笔交易的原因**" |
| **林肯的裁决** | 把尾巴叫作腿，它还是四条腿——"**哪怕审计师愿意出证明说那尾巴是腿**" |

## 第九夜 · 掌声

| | |
|---|---|
| **核心场景** | 一九九一年八月十八日，他成为所罗门的临时董事长："我把嘴放在了我们的钱在的地方" |
| **底层规则** | 名誉是**唯一一种只能用一次就破产的资本** |
| **反常识** | **警惕那些产生掌声的投资活动；真正的大动作，通常得到的是哈欠** |
| **反人性** | **认可麻醉大脑**，使之对新事实、对重新审视既有结论更不敏感 |
| **关键判词** | "不愿意立刻面对坏消息，正是把所罗门的一个本可轻易处理的问题，变成几乎导致一家八千名员工的公司灭亡的原因" |
| **制度设计** | 四条备忘录规则：守护声誉／把"头版测试"当标准／"别人都这么做"等于想不出理由／**球场中央有足够多的钱可赚** |
| **原型** | **人格面具与阴影的正面交锋**。他用第三人称自称"你们的董事长"——面具本身就是他的武器 |
| **呼应** | "我们愿意显得愚蠢，只要我们不觉得自己行事愚蠢" |

## 第十夜 · 方舟

| | |
|---|---|
| **核心场景** | 一九三九年的家书与一千美元现金，在保险箱里放了三十一年，一九七〇年才被重新读到 |
| **底层规则** | **诺亚法则**：如果一艘方舟可能是生存所必需的，今天就开始造它，不管天空看起来多么无云 |
| **反常识** | **保守不是为了不输，是为了在别人挣扎时能够进攻** |
| **反人性** | 人在无云的时候不愿造船；在有雨的时候来不及造船 |
| **关键判词** | "我们永远不会拿你们的钱去玩财务上的俄罗斯轮盘——**哪怕那把枪有一百个弹膛，只有一颗子弹**" |
| **最诚实的一句** | "**我认识到了。但我没有把想法变成行动。**"（二〇〇一年，九一一） |
| **算术** | "如果一件事在给定年份发生的概率是三十分之一，那么它在一个世纪里至少发生一次的概率是 **96.6%**" |
| **代价** | 在大多数年份——实际上是大多数十年——谨慎被证明是不必要的。"就像给一座被认为防火的堡垒式建筑买的保险" |
| **原型** | **智慧老人**的最终成形；方舟作为"自性"（Self）——容纳一切的那个容器 |

## 第十一夜 · 十二个决策

| | |
|---|---|
| **核心场景** | 二〇二二年，他给自己的工作下总评："大部分资本配置决策都不比马马虎虎更好" |
| **底层规则** | 五十八年，**一打**真正出色的决策——**大约每五年一个** |
| **反常识** | **最贵的错误是"没买"**——芒格："几乎所有巨大的错误，都发生在没有买"；而错过的错误**从不留下痕迹** |
| **反人性** | 只有做错的事会被记录，没做的事不会被记录。因此人系统性地高估了"行动" |
| **心理学原型** | **个体化完成**——把阴影整合进自我。他用一整封信去写自己一生最贵的三个错误，并给出量化的伤害 |
| **错误清单** | NICO 买错主体（$1,000 亿）／Dexter 用股票支付（$60 亿）／精密铸件买贵（$110 亿减记）／乐购拖延（$4.44 亿）／EFH 没和查理商量（$8.73 亿） |
| **六字收尾** | "**下次我会打电话给查理。**" |
| **识人** | 皮特·利格尔的十万美元年薪／本·罗斯纳六年级／"**我从不看候选人在哪里上学。从不！**" |

## 第十二夜 · 最后一封信

| | |
|---|---|
| **核心场景** | 二〇二三年十一月二十八日，查理去世，距百岁生日三十三天 |
| **底层规则** | **什么东西能活得久**——不是公司（公司会死），不是钱（纸币会蒸发），**是人和人之间的那根线** |
| **反常识** | 一个算了一辈子复利的人，最后说出口的是关于**运气**的 |
| **反人性** | 最伟大的合作者从不记账——"**当我犯了错，他从不——从不——提醒我**" |
| **最后比喻** | **建筑师与总包工头**："浇筑混凝土、安装窗户的人，很快就被遗忘" |
| **六十年账本** | 一九六五年：一分钱所得税都没缴 → 二〇二四年：$268 亿，全美企业税的 **5%**；六十年只发过一次股息：**$101,755** |
| **最后一次对国家说话** | "照顾好那些并非因自己的过错、在生活中**抽到短签**的人。他们值得更好的" |
| **最后一句** | "**我赌她会被男性包围。**"——九十四岁的老人，打赌九十一岁的妹妹在年会上会被男人围着 |

# 全书的反常识清单

> 这一节，是这十二夜真正要留下的东西。每一条都与人的本能相反。

## 关于价格与价值

1. **股价下跌是好事**——对任何未来仍是净买入者的人。人在为即将买入的汉堡包涨价而欢呼。
2. **便宜是昂贵的**。雪茄烟蒂的最后一口是免费的，但你买下的是一艘长期漏水的船。
3. **贵的好生意优于便宜的平庸生意**。一英尺高的栏架胜过跨七英尺的本事。
4. **流动性从无条件的好处，变成了诅咒**。有报价的人比没报价的人更容易变穷。

## 关于风险与生存

5. **负债可以是资产**。欠一美元而它永远不会离开，与欠一美元而它明天出门，是两个世界。
6. **保守不是为了不输，是为了在别人挣扎时能够进攻**。
7. **用你需要的，去赌你想要的，是疯狂**——哪怕那把枪有一百个弹膛，只有一颗子弹。
8. **要跑第一，你首先得跑完**。

## 关于人与组织

9. **好生意比好经理重要**。留下来的往往是那家企业的名声。
10. **不是腐败或愚蠢把企业推上歧路，是制度动力**。每个参与者在自己位置上都是对的。
11. **信任比审计便宜**。一句实话胜过一份尽职调查报告。
12. **掌声是腐蚀剂**。真正的大动作，通常得到的是哈欠。

## 关于语言与思考

13. **糟糕的术语，是良好思考的敌人**。当"损失"被称为"发展"，人就不再为它负责。
14. **把尾巴叫作腿，它还是四条腿**——哪怕审计师愿意出证明。
15. **摆脱旧观念，比学会新观念难得多**（凯恩斯）。

## 关于错误与时间

16. **最贵的错误是"没买"**，而它从不留下痕迹。
17. **承认错误比掩盖错误便宜**。拖延纠错是最大的罪——芒格把它叫"嘬手指"。
18. **一个由不断认错构成的成功故事**：五十八年，一打决策，每五年一个。
19. **什么东西能活得久**——不是规模，不是速度，不是聪明。**是那些每天挖一铲、不说话的东西。**
